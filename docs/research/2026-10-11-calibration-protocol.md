# 预登记：训练内选择概率收缩，而非验证期调参

沿用冻结 1268 条真实输入和指纹 `fbca9db1f618ee5f7b144c6f32ab155352f3a5dd4d8de7eece854602409fa68d`。原外层开发集及最终留出集仍封闭；不得添加日期、改变特征、种子、中性阈值或为提升分数补值。

假设：当前五轮逻辑回归过度自信，训练内校准可以降低其概率误差，且需要单独验证是否形成方向优势。不能只改善概率误差就宣布涨跌预测提高。

使用相同三个240条内部验证块，每块的既有训练区先按 `targetDate < validationStart` 排除未结算标签；最后120条作为校准区，前面作为模型拟合区，进一步要求拟合 `targetDate < calibrationStart`。外层训练仍至少500条，内部拟合预先允许至少400条。标准化及类别频率仅来自内部拟合区。两次隔离后的预计拟合数为426/666/906，实际不足则停止，不扩展范围。

在内部拟合区训练固定 ALL_36、五轮、默认seed=12345、标准化、无权重逻辑回归。概率基线使用同一拟合区类别频率。校准不改变该模型：候选概率为 `(1-w)*模型概率 + w*拟合期频率概率`，权重w只最小化120条校准区的平均LogLoss。目标是一维凸函数，用边界导数及固定80次二分求最优，不搜索验证期。若真实类别零概率导致数学条件不满足则保留失败，不补造概率。

模型拟合与校准后均不在整训练区重拟合。对照为同一内部拟合模型的未收缩概率，主要能力基线为同一拟合区频率概率；与上一轮使用全部547/787/1027条拟合的成绩不直接相减。

记录全部校准及验证逐日概率、真实标签、时间边界与权重。预登记源码、规则后只运行一次。先验证概率与业务边界，再独立复算校准导数、权重和验证评分。每块完整240条按固定argmax比较准确率、三类召回、平衡准确率、Brier和LogLoss；0.55信号门槛另报，不能替代全人群指标。

判定：若候选方向准确率不能在三个块都高于频率基线且概率指标一致改善，不支持稳健优势。w=1只等于退回基线，不算模型提高；w接近1也不能将多数类命中归功于模型。即使验证表现更好，已看过这批内部日期，仍不是新盲测，不能晋级或宣称未来准确率稳定。原始失败和正式预测均不覆盖。
