# 黄金次日模型：真实宏观历史版本与非线性对照

## 结论

**当前固定配置没有产生可晋级的候选，也没有证明未来预测准确率提高。** 同日期多数类基线命中 347/720（48.19%）；线性最高 345/720（47.92%），树模型最高 338/720（46.94%）。正式模型、配置和预测记录均未修改。

这次回答的是“求解充分以后，宏观历史版本和现有 XGBoost 能否带来增量”，不是最新行情回测。验证日期为 2022-02-02 至 2024-11-07，是已查看过的内部诊断区间，不能作为新盲测或最终留出集验收。

## 固定口径与可追溯性

- [协议](2026-10-02-macro-model-protocol.md) 在读取本轮模型分数之前写入工作区；不是外部预注册。
- 真实 `twelve_data / XAUUSD` 4382 根日线，SQL 只读 `2024-11-11` 之前的价格。2024-11-08 用于结算最后一个标签；不查询旧外层开发集、最终留出集的价格和标签。
- 产品 `GoldDatasetBuilder` 生成 1500 条完整 36 特征样本，2019-02-05 至 2024-11-07。各组合使用相同训练日期、结算标签和验证日期，不以补零扩大样本。
- 宏观使用 FRED 历史有效版本，最多采用基准日前一完整日已知版本；来源为 DFII10 和 **DTWEXBGS 广义美元指数，不是 DXY**。归档请求截止日期 2026-09-29 不等于观测数据已经更新至该日。
- 3 折各 240 条验证样本；训练分别 779/1019/1259 条，训练 `targetDate` 严格早于验证起点。标准化仅拟合各折训练样本。
- 标签是既有 ±0.5% 三分类：上涨、震荡、下跌。这里的“准确率”不是不带震荡区间的简单涨跌命中率。
- 线性参照采用无正则多分类交叉熵、Newton-SVD；9 次拟合均达到完整三类最大梯度 ≤1e-6，4–5 个检查点。没有按验证分数提前停止。
- ALL_36 三折最终 Hessian 数值秩均为 70/74，保留的非零奇异值条件数约 1.65e12–1.83e12。达到本次预定梯度阈值不保证系数唯一或稳定；高共线/病态也是需要检查的因素，不能把树模型相对它多命中 23 次解释成纯粹的非线性收益。
- XGBoost 固定 200 棵树、深度 3、eta=0.03、minChildWeight=5、行/列抽样 0.8、lambda=1、alpha/gamma=0、单线程、种子 20260901；不按本轮结果调参。
- 多数类基线的概率来自各折训练类别频率，不采用验证频率，也不伪造 one-hot 概率。

产品基准提交为 `5fb29c1b0f729d6771b548ad525a8ee9a1476695`；新研究源码以结果中的 `sourceHashes` 标识。完整内容摘要为 `4ce352acbb854dd4e7e6d2de67c3426f0f62f360b76cf267559d57df07ea0dd3`，含全部日期、标签、36 项特征。数据集来源指纹、日线摘要、宏观文件摘要、协议摘要、逐日概率及训练轨迹保存在 [原始结果](2026-10-02-macro-model-check.json)。

价格是数据库当前保存的真实历史日线，不是历史修订版本或逐时可用性快照；本轮未消除供应商事后修订和日内发布时间的所有风险。FRED 历史版本隔离也不能被扩大解读为逐时新闻/行情输入已经完全可追溯。

## 门槛与决定

按协议复算：全样本平衡准确率至少超过同组合线性 2pp、信号准确率超过同信号日期基线、覆盖率≥30%、已覆盖信号三方向召回均≥25%、全样本 Brier/LogLoss 不劣于线性、全样本准确率超过多数类。所有组合均不通过；全样本三方向召回也完整报告，避免利用筛选后的命中率掩盖涨跌能力。

- BASE_16：仅覆盖率通过。
- OHLC_20：仅同日期信号基线通过，其他门槛均失败。
- ALL_36：仅 Brier/LogLoss 优于同组合线性，其他门槛均失败。
- `promotionAllowed=false`。原始 `ForecastMetrics.promotionReady` 只是类别完整性字段，不构成晋级许可。

## 接下来做什么

1. 保留正式模型，页面结论仍应按当前模型展示，不能把本研究分数替换成“线上准确率”。
2. 下一项研究优先检查共线和过拟合，预先固定一个小规模正则化对照；同时检查类别失衡、涨跌召回与概率校准。类别重加权另作**独立的待验证假设**，仍检查总体概率误差和覆盖率，不能靠增加涨跌猜测数制造提升。
3. 只有预先固定的有限对照在开发区间优于同日期基线，才冻结参数并安排真正未参与选择的时间段；已查看的留出结果不能重新称为盲测。
4. 真实未来预测继续保留生成时间和当时输入，按下一真实交易日结算。算法修正是否改善未来效果仍需这些新样本验证，无法承诺目标命中率。

这份报告只说明已完成的固定对照；第 2–4 项不是已经实现或已经有效。
