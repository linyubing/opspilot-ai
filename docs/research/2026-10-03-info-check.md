# 当时可用宏观信息审计：缺失不是720条旧验证错判的直接解释

## 本轮结论

本轮完成真实信息审计，**没有训练新模型、没有提高或修改正式预测准确率**。固定树实验的720个验证基准日，两条宏观序列当时均有完整21条非缺失窗口；370次错判也全部具有该窗口。因此不能把这些错判简单解释为“宏观数据拿不到”。固定树本来只使用20维OHLC，这里的宏观窗口是信息审计，不是该树实际使用的输入。

另一个明确限制是：按真实历史版本筛选，宽基美元指数归档在2019年以前没有可用输入。全部4361条黄金输入中只有1500条拥有完整联合宏观窗口，首个日期为2019-02-05。**把宏观完备性作为整个黄金训练集的前置条件，会排除2861条黄金样本。** 这不是用零补宏观的理由，也不能据此断言减少历史样本必然是失败主因。

## 审计边界

- 按[事先固定协议](2026-10-03-info-protocol.md)，复用并先独立验收原固定树的4361条输入及720条预测；不重算新预测，不调参数、标签、新鲜度或信号阈值，不读取最终留出集。
- 720条覆盖2022-02-02—2024-11-07，**是已反复研究的旧内部验证，不是2026最新行情或新盲测**。黄金目标严格早于2024-11-11。
- Java实际调用生产`FredHistoryStore`加载一次，逐日选择D-1已知的最多21条窗口；独立Node从原始FRED文件重选并逐日期核对数量、最新观测/值/UUID、全部窗口摘要。
- `DFII10`为实际利率，`DTWEXBGS`为宽基美元指数，**不冒充DXY**。本轮来源摘要与既有宏观模型实验逐项一致。
- 观测日龄从最新观测日到预测基准日计算；自然日不是交易日。采集时间不作为发布时间，历史版本仅证明日级版本边界，不证明盘中可得时刻。
- 日龄分组是研究描述，**不是生产新鲜度硬门槛**。当前快照计算不会因本轮分组而自动拒绝日期。

## 失败解释：证据能说什么、不能说什么

1. **“没有宏观数据所以预测错”不成立为这批验证的直接解释。** 370个错判日都有真实完整窗口；但固定树没有读宏观特征，因此不能写成“模型已利用宏观却无效”。此前同一1500条群体的宏观模型实验未形成可晋级优势，不在本轮重跑或包装成新成果。
2. **较旧日龄分组命中率较低，但不能做因果归因。** 宽基美元超过7日组的91次错判只占全部370次错判的24.59%，不是全部错判的主体。其同日期多数类准确率也较低，反映类别分布不同，不能直接用两个分组的总体准确率差证明信息延迟造成预测失败。
3. **日龄与星期相关。** 评分后附加查看日期组成：超过7日的167条中144条周一、21条周二、2条周五；4—7日组为123条周二、145条周三、145条周四、140条周五。这是明确标注的事后描述，不是预注册新子组或可交易规律，不能据此优化星期过滤器。
4. **宏观训练范围与黄金历史范围不能混为一谈。** 4361条中2861条没有当时可用宽基美元观测；其余1500条均完整。实际利率全部可用，日龄分组2256/2104/1条；宽基美元完整组为1151条4—7日、349条超过7日。只比较完整历史OHLC模型与截短宏观模型的分数，会同时改变特征和训练群体；不能把差异全部归为宏观特征好坏。

当前证据排除了窗口选择/未来版本混入的明显错误，记录了信息覆盖限制，**仍未找到足以修复370次错判的单一原因**。没有真实事件、当时可得新闻或日内观测的完整证据，不能编造逐日原因。

## 下一轮可检验方向（本轮未执行）

围绕已证实的覆盖限制，下一轮可固定一个“保留完整黄金历史，同时只在真实可用宏观窗口上训练独立宏观模型”的后融合对照：黄金分支不被宏观缺失截短，宏观分支不补零，预测概率按事先固定规则结合。它是信息利用假设，不是已证明的改善；须先固定真实输入、训练隔离和组合规则，再比较同日期完整指标、涨跌召回及新增命中/新增错判。

```powershell
$infoCp = 'target/classes;target/probe-classes;' + (Get-Content 'target/probe-classpath.txt' -Raw).Trim()
javac -encoding UTF-8 -cp $infoCp -d target/probe-classes ../docs/research/probes/InfoRun.java

java -cp $infoCp com.opspilot.ai.macrodata.InfoRun target/info-local.json $infoCommit
```

```powershell

$infoPrevAudit = $env:INFO_AUDIT_FILE
try {
    $env:INFO_AUDIT_FILE = 'backend/target/info-local.json'
```
