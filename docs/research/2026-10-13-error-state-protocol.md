# 现有收敛模型的失败状态审计

只读冻结1268条输入与 `2026-10-11-fit-reference-result.json` 三折36维收敛逻辑回归。原模型和诊断成绩已看过，本轮明确为事后归因，不是盲测、不训练、不晋级、不筛掉失败样本。目标是检验错误是否集中在预测前可观察的状态，不根据本轮结果选择过滤门槛。

1. 精确复用原三折训练与诊断日期，训练标签targetDate严格早于诊断起点；诊断每折120条，共360条。所有目标早于2024-11-11。
2. 重新从各折训练特征拟合均值/标准差，复算已归档权重的概率并核对每一条，不改变权重。训练集是拟合内结果，只能用于对比，不充当训练期样本外证据；各折训练人群重叠，不合计为独立样本。
3. 固定概率分箱：[1/3,0.5)、[0.5,0.6)、[0.6,0.8)、[0.8,1]。同时固定报告现有0.55出信号条件，三方向概率平局按现有策略不出信号。
4. 极端输入定义为任一非零训练标准差特征的abs(z)>3，均值/标准差只来自该折训练。这个工程标记不证明输入分布外，也不假设所有特征服从正态；训练常量列另外列出诊断变化，不能被z=0掩盖。
5. 每个分箱/状态均保留样本数、准确率、同样本频率基线、平均最大概率、置信度差、Brier与LogLoss、类别混淆矩阵。逐折报告训练内和诊断差异，不只看合并最优箱。
6. 逐条记录置信度、最大绝对z及对应字段、预测与实际类别。这些字段是预测前可计算的状态，命中标签只作事后诊断；不将本轮标签反推出新预测规则。
7. 若某状态只在个别折较好，或高置信度仍落后，不用它直接部署。任何后续过滤器必须在新的时间隔离流程中先冻结，再验证覆盖率和同样本基线，不能把少出信号包装成真实准确率提高。
