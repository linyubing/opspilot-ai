# 真实小时线替代路线：已验证可行，不等于正式日线已修复

## 本轮要解决什么

原供应商日线存在重复日期，直接同步仍应拒绝。缺少另一家已验证的OHLC数据源，不代表只能停工：本轮取已有授权的真实小时线，验证独立的连续聚合研究口径，并实际调用本地模型。没有修改正式供应商日线、正式预测或历史准确率。

## 固定研究合同

- 标识：`TWELVE_HOURLY_UTC21_RESEARCH_V1`。
- 输入：Twelve Data `XAU/USD`、`1h`、显式请求 `timezone=UTC`。
- 回执的元数据使用 `currency_quote=US Dollar`、`type=Precious Metal`，没有回显时区；不伪造时区响应字段。
- 窗口：UTC 21:00至次日21:00，左闭右开；这是预先固定的研究窗口，不是根据本轮价格匹配选择的窗口。
- 每个窗口必须有24个唯一、整点的小时起始时间；窗口连续且不重叠。收盘取最后一根小时线的close。
- 只取已结束窗口。缺失不补零、不前向填充、不跳过缺口拼出21个样本。最新连续完整窗口不足21个时拒绝预测。
- 不把24/7合成报价日称为伦敦金交易日；不能替代京东黄金报价、伦敦金官方日线或可执行买卖报价。
- 官方说明该数据源是包含XAU的24/7组合报价，周末有数据不代表伦敦市场开市：[Forex API v2](https://support.twelvedata.com/en/articles/12520817-forex-api-v2)。

## 本地模型真实调用与失败分析

使用 `127.0.0.1:11435` 的 `qwen3.5:9b`，校验模型摘要：

`6488c96fa5faab64bb65cbd30d4289e20e6130ef535a93ef9a49f42eda893ea7`

仅提供真实聚合窗口的1/5/20期收益率、20期均线距离和窗口波幅，不补造宏观、新闻、DXY。

第一次研究合同v1失败：五项事实数值均被正确复制，但模型把正数 `range1` 的符号写成 `FLAT`。同时“没有上涨动力，所以横盘”的文字不能排除下跌，不足以支持中性分类。保留完整失败回执，未输出有效预测、未计入准确率。

针对性修正v2：事实数值和符号由程序保留，模型只返回方向及引用编号，禁止未知或重复引用；明确要求考虑三个方向，并解释波幅不等于方向。没有重试v1来挑选好结果。

v2真实调用于 `2026-10-08T12:38:10.9008950Z` 创建，`12:38:12.1193171Z` 返回，引用合同通过，输出 `BEARISH`。这只表示本轮独立研究输出看跌，不表示预测正确。程序引用校验不能证明自由文本或方向正确。

目标：`[2026-10-07T21:00:00Z, 2026-10-08T21:00:00Z)` 末收盘相对基准末收盘的三分类（阈值±0.5%）。目标末时刻为北京时间10月9日05:00。请求时目标窗口已开始，因此强制标注 `IN_SESSION`，不是“明天黄金交易日开盘前预测”，也不是实时价格涨跌判断。

- `researchOnly=true`
- `productionEligible=false`
- `officialSessionCertified=false`
- `trustedAccuracyEligible=false`

两次调用是同一数据下的失败修正对照，不是两个独立样本，不产生准确率提升结论。

## 后续实现边界

这轮已经验证“连续真实输入→本地模型独立研究”的路线，不再把日线故障当作所有研究都无法继续的理由。但正式页面仍未切换，原日线供应商问题仍存在。

1. 为该口径建立独立的输入、预测和结算记录；保存源回执摘要、聚合版本、窗口边界、生成时间和输入截止时间。
2. 页面分开显示原正式日线与小时聚合研究，不重标旧记录、不合并旧准确率。
3. 下一窗口结束后重新取得真实小时线，以同口径结算；盘中研究单独统计。新近预测必须保存后再见目标价格，不能事后补写。
4. 先验证稳定采集、结算及同人群基线，再评价准确率。正式“下一黄金交易日”仍需匹配明确的市场日历及数据合同，不能偷偷用24/7窗口替代目标。
5. 不打开既有最终留出集，不晋级正式模型，不承诺买卖或重仓能力。
