# VIX增量实验：评分前固定协议

## 问题与范围

检验D-1已知的真实VIX信息是否改善黄金次日方向区分。根据[路线评估](2026-10-03-route-review.md)，本轮不搜索阈值、标签、正则强度或特征组合，不更换正式模型，不读最终留出集。

VIXCLS是股票市场预期波动指标，不是黄金波动或DXY。本实验只检验一个有限假设，不承诺改善。

## 输入与四个固定特征

使用已采集两次并核验一致的本地真实历史版本。调用生产`FredHistory.recent(D,21)`，按D-1有效区间选值；独立Node版本选择器逐日期复算。序列降序，`v[0]`最新，`v[20]`最旧：

- `vixLevel = v[0]`。
- `vixChange1 = (v[0] / v[1] - 1) * 100`。
- `vixChange5 = (v[0] / v[5] - 1) * 100`。
- `vixChange20 = (v[0] / v[20] - 1) * 100`。

这些是观测期变化，不冒充连续自然日变化。只接受完整21条有限正值，缺失不补零、不回填旧版本。记录最新观测日期与完整窗口摘要。725个早期黄金输入不具备完整历史窗口，仅排除训练中的这些日期；720验证日期全部保留。不根据最终分数或观测日龄筛选样本。

## 对照与拟合

固定原三个240条开发验证折，日期2022-02-02—2024-11-07，全部目标早于2024-11-11。沿用原次日三方向标签、0.55覆盖阈值。

1. 匹配训练日期的价格模型：20个原OHLC特征。
2. 匹配训练日期的候选：相同20个OHLC特征加上述4个VIX特征。
3. 相同训练日期的多数类基线。
4. 已冻结完整历史价格结果仅作额外参照，不作为不等样本条件下的因果对照。

三折匹配训练数量2915/3155/3395，训练目标必须严格早于各验证折开始。每个分支独立用自身训练集拟合标准化，不读验证均值/方差。使用现有中心化L2多分类逻辑回归，lambda=0.01，既有最大迭代100、梯度≤1e-6收敛要求不变。未收敛明确失败，不自动换求解参数。每个分支重复拟合及完整导出两次。

## 固定判断标准

逐折与全部720条报告准确率、平衡准确率、三方向召回、Brier、LogLoss、混淆矩阵及新增/丢失命中。覆盖信号必须在相同日期与价格及多数类比较，不与全日期基线混比。

完整诊断门槛：候选准确率同时高于匹配价格与匹配多数类；平衡准确率至少比匹配价格高0.02；三方向召回均≥0.25；Brier及LogLoss均不劣于匹配价格。信号门槛：覆盖≥0.30，同日期准确率超过匹配价格和多数类，覆盖信号三方向召回均≥0.25，缺类记null并失败。

任何门槛未过，如实记录；不重新选择窗口、删除差折或修改标签。即使通过也只是旧开发数据诊断通过，不晋级、不证明真实未来准确率。若失败，回到信息与预测时点的路线评估，不自动启动另一个指标搜索。

## 实施与验收顺序

1. 四特征手算、非法输入与窗口边界先RED后GREEN。
2. 生产历史加载器导出真实4361日期的窗口与特征，独立重选版本和公式验证；缺失保持null。只写新的本地target文件，不覆盖或删除已有证据。
3. 同日期匹配训练，两个模型及多数类计算，重复导出；独立复核训练日期、缩放、收敛、概率和全部指标。
4. 记录失败原因与前轮关系；完整项目回归、代码审查、提交与推送。

目前协议冻结于模型评分前。数学夹具不作为市场数据；原始窗口/特征只保存在忽略的本地target，不新发布逐条行情。来源、协议及计算依赖以SHA绑定。
