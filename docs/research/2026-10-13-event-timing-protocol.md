# 固定时距诊断：延迟一天是否足以解释单CPI规则失败

假设：既有意外符号规则没有稳定优势，可能与D-1保守政策引入额外一天延迟有关。仅检验此假设，不新增指标、不重训、不调符号、意外阈值或黄金±0.5%标签，不改变正式预测目标。

机会人群仍为2023全年12次加2024年1至10月10次。原来源缺失与版本拒绝共4次保留。2024年6月和7月BLS实际归档注明当天重发，精确重发时间未认证；本轮比较发布当天可用性，额外拒绝这2次，不能假定更正版本在下一会话开始前已存在。剩余16次事件的同一意外值和方向规则不变。

每条事件同时保留两个时距：

- EARLY：发布日收盘到下一配置交易日收盘。CPI发布时刻08:30美东早于当前候选黄金20:00UTC边界，但没有原始历史预测发布凭证，故只做归档事件的时距诊断，不声称真实事前预测已发生。
- DELAYED：上一协议的发布后首个配置交易日收盘到其下一配置交易日收盘。

两个时距的标签对应不同日期，不能把分数差说成同标签模型修复的因果效果。目标仍分别为一个日线会话，不换成公告后小时预测。新协议只回答“提前到发布日是否自动取得稳定优势”，不能证明市场反应的唯一原因。

各自二行必须通过生产确认、配置日历连续性、唯一XAUUSD/twelve_data来源；不顺延缺行、补价格或读2024-11-11及以后的最终留出。原收益分类与意外方向固定。基线分别仅统计冻结样本中targetDate严格早于各自基准日的标签，并在相同信号事件上比较。

全部22次机会保留缺失/版本拒绝及重发拒绝；有效16次中精确零意外继续NO_SIGNAL。无概率，Brier/LogLoss为空。逐年及合计同时报告，不能选择较好时距部署；已见历史诊断不作为未见验收。
