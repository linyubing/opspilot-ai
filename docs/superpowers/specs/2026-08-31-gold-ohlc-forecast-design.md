# 黄金 OHLC 预测口径改造设计

## 背景

当前正式预测和历史回测主要使用 `MarketPrice.referencePrice`。该字段来自黄金基准价序列，不能代表伦敦金每日收盘价，因此旧回测结果不能继续作为收盘方向预测的准确率依据。

项目已经接入 Twelve Data 的 `XAU/USD` 日线，并保存真实的开盘价、最高价、最低价和收盘价。后续预测、结算和回测必须统一使用这套 OHLC 数据。

## 目标

- 使用真实 `XAU/USD` 日线，不生成或补造行情。
- 使用 `close` 作为预测基准价、目标价和收益率计算价格。
- 使用 `open/high/low/close` 构造波动特征。
- 正式预测、预测结算和历史回测使用完全相同的价格口径。
- 页面明确展示数据日期、OHLC、数据提供方和采集时间。
- 没有真实 OHLC 时明确失败，不回退到旧基准价。

## 非目标

- 本阶段不执行自动交易或下单。
- 不承诺固定胜率。
- 不把周末报价当作黄金交易日。
- 不删除旧基准价数据和旧回测记录。
- 不让大模型直接计算数值预测结果。

## 核心决策

### 价格口径

每日方向定义为目标交易日收盘价相对基准交易日收盘价的变化：

```text
收益率 = (目标日 close - 基准日 close) / 基准日 close
```

超过上涨阈值为上涨，低于下跌阈值为下跌，中间区域为震荡。阈值继续由回测配置控制，不在本次改造中重新定义。

### 数据真实性

正式链路只读取 `gold_daily_bar` 中 `symbol=XAUUSD`、`provider=twelve_data` 的记录。缺少目标日期时保持待结算；缺少构建预测所需的历史窗口时拒绝生成预测。

实际利率和美元指数允许读取分析日之前最近一条真实观测，并在结果中保留各自原始日期。该处理属于“截至当日可获得的信息”，不是伪造同日数据。

### 旧数据隔离

旧 `MarketPrice.referencePrice` 继续保留，供旧功能和数据核对使用。新生成的预测和新回测不得混用它。旧回测页面应显示“旧基准价口径”，新回测显示“OHLC 收盘口径”。

## 组件改造

### 黄金日线仓储

扩展 `GoldDailyBarRepository`，支持：

- 查询指定日期或之前最近一根日线；
- 查询日期区间内按时间升序排列的日线；
- 查询基准日之后的下一根有效交易日线。

仓储只负责读取真实记录，不在缺失日期时生成数据。

### 研究快照

`GoldResearchSnapshotService` 改为读取黄金 OHLC：

- 当前价格使用最新日线 `close`；
- 1、5、20 个交易日收益率使用对应日线 `close`；
- 波动率使用收盘到收盘收益率；
- 新增日内振幅、实体涨跌和收盘位置特征。

宏观数据继续按“截至分析日最近可用观测”对齐，并保留数据日期用于新鲜度判断。

### 预测生成与结算

预测生成时把基准日 `close` 写入预测记录。下一交易日由真实黄金日线序列决定，不通过简单加一天推断。

结算时读取基准日之后第一根真实日线，以其 `close` 计算实际收益率和方向。如果日线尚未到达，预测保持待结算状态。

### 历史回测

回测按时间正序运行，每个样本只能使用当时已经存在的数据：

1. 以某根真实黄金日线作为基准日；
2. 只读取该日及之前的黄金和宏观数据；
3. 生成预测；
4. 使用下一根真实黄金日线 `close` 结算；
5. 汇总方向准确率、覆盖率、各方向准确率和波动区间表现。

样本不足或因数据缺失被跳过时，页面必须显示数量和原因。

### 页面展示

预测页新增真实行情区域：

- 基准交易日；
- 开盘、最高、最低、收盘；
- 下一目标交易日；
- 数据提供方；
- 采集时间；
- 行情是否足够新鲜。

回测页新增“价格口径”字段，防止旧结果与新结果混淆。

## 错误处理

- Key 未配置：返回配置缺失错误，不输出 Key。
- Twelve Data 拒绝请求：保留上游错误分类，不保存不完整响应。
- OHLC 为空或数值非法：整批拒绝。
- 历史窗口不足：返回数据不足，不生成低可信预测。
- 目标交易日尚无真实日线：保持待结算，不猜测目标价格。

## 测试策略

- 仓储测试：日期边界、排序和下一交易日查询。
- 快照测试：所有收益和波动特征均来自 `close`。
- 预测测试：基准价来自基准日 `close`。
- 结算测试：目标价来自下一根真实日线 `close`。
- 回测测试：严格按时间切片，不读取未来数据。
- 接口测试：日期格式、OHLC 字段和数据来源完整。
- 端到端验证：使用已同步真实数据重新执行最近行情回测，并与数据库原始 OHLC 抽样核对。

## 实施顺序

1. 扩展黄金 OHLC 仓储查询能力。
2. 让研究快照改用 OHLC 收盘价和波动特征。
3. 让预测生成与结算改用真实下一交易日。
4. 让历史回测改用相同 OHLC 口径。
5. 在预测页和回测页展示价格口径与数据来源。
6. 重新运行历史回测，旧准确率不再作为新模型结论。

每一步独立进行红灯测试、实现和相关回归，确认通过后再进入下一步。
