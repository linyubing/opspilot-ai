# 下一交易日类别加权对照计划

## 目标与边界

检验此前下跌召回不足是否能通过训练损失加权改善。改善与否由真实数据结果决定，不承诺准确率提升，不切换正式模型。

## 运行前固定的实验

1. 仅 NEXT_DAY；固定 BASE_16、OHLC_20、ALL_36 三组，不追加权重搜索。
2. 对照两侧都标准化：未加权 Logistic 与类别加权 Logistic。其余训练参数、种子、标签及 0.55 信号阈值保持不变。
3. 权重为 `N/(3*该类别训练数量)`，每次滚动训练独立计算。缺少类别则报错，不补造、复制行情样本。标准化也仅拟合当前训练折。
4. 数据集构建一次、分区一次；复用现有每 20 条样本重训的管线，仅纳入目标日早于本区块的已结算样本。最终留出集不用于拟合、评分或选优；区间元数据与全数据指纹会涉及留出样本。
5. 沿用既有真实数据库快照，不同步新行情。运行后核对 NEXT_DAY 指纹及未加权指标是否与上一轮标准化实验完全一致。

## 验收顺序

1. 行为测试先失败后通过：类别权重公式、真实训练效果、共享数据分区及 HTTP 入口。
2. 完整回归通过；只读代码审查；提交实现后用该提交哈希启动。
3. 调用一次 `POST /api/research/gold/model-experiments/scaling-check/balanced`。
4. 保存原始响应和中文结果表，包括全样本命中率、三类召回、平衡准确率、信号覆盖率、同信号日期多数类基线、Brier、LogLoss、连续区块与配对胜负。
5. 无论成功或失败均记录；不因开发集指标改善自动晋级。

## 解释限制

- 加权输出不等于校准后的市场概率；必须检查概率误差，不能将较高分数解读为更可靠。
- 同一开发集的重复实验不构成独立验证。既有宏观因子的历史发布时点与修订版本风险仍未闭环。
- 合成输入只用于算法单元测试；真实实验只读已入库行情，不混入测试样本。
- 本批不是最新交易日预测，也不是买卖或重仓依据。
